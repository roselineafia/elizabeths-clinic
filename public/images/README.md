## Official logo

`clinic-logo.png` is the supplied clinic logo. The footer shows the complete lockup on a white panel, because the artwork has a white background. The header uses `clinic-mark.png`, the circular emblem cropped from that same logo, beside the clinic name. The favicon is the same emblem.

To replace the logo later, save the new artwork as `public/images/clinic-logo.png` and update `clinic-mark.png` to match. If `clinic-logo.png` is removed, the header and footer return to the temporary wordmark.
